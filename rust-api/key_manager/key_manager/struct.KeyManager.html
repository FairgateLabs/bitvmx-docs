key_manager::key_manager

Struct KeyManager

Source 
pub struct KeyManager { /* private fields */ }
Expand description

This module provides a key manager for managing BitVMX keys and signatures. It includes functionality for generating, importing, and deriving keys, as well as signing messages using ECDSA, Schnorr and Winternitz algorithms. The key manager uses a secure storage mechanism to store the keys.
