Expand description

Core hashing functionality for Winternitz One-Time Signatures.

This trait defines the interface for hash functions used in WOTS. The hash function is applied iteratively W times (where W = 2^NBITS - 1) to create and verify one-time signatures.

§Security Note

Winternitz signatures are one-time use only. Reusing a key pair compromises security and allows signature forgery.
