pub fn is_fatal(&self) -> bool

Returns whether the error should be considered fatal.

NOTE: For now, we mark all errors as fatal to avoid masking issues and ensure coordinated shutdown paths are exercised. Once the system is stable, we should revisit this and separate truly fatal errors (e.g., storage corruption) from recoverable ones.
