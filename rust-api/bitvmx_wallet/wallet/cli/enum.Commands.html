Expand description

Available subcommands for the BitVMX wallet CLI.

This enum defines all the available subcommands that can be executed through the command-line interface.

Variants§

§

SendToAddress

Send funds to a Bitcoin address.

Creates and broadcasts a transaction to send the specified amount to the given Bitcoin address.

§Arguments

  • identifier - Wallet identifier
  • to_address - Destination Bitcoin address
  • amount - Amount to send in satoshis
  • fee_rate - Optional fee rate in satoshis per virtual byte

Fields

§identifier: String

Wallet identifier

§to_address: String

Destination Bitcoin address

§amount: u64

Amount to send in satoshis

§fee_rate: Option<u64>

Optional fee rate in satoshis per virtual byte

§

SyncWallet

Synchronize a wallet with the Bitcoin network.

Downloads and processes all blocks and mempool transactions to update the wallet’s state to the latest blockchain state.

§Arguments

  • identifier - Wallet identifier

Fields

§identifier: String

Wallet identifier

§

CancelTx

Cancel a pending transaction.

Removes a transaction from the wallet’s pending transaction list. This is useful for transactions that haven’t been confirmed yet.

§Arguments

  • identifier - Wallet identifier
  • txid - Transaction ID to cancel

Fields

§identifier: String

Wallet identifier

§txid: String

Transaction ID to cancel

§

ListUnspent

List all unspent transaction outputs (UTXOs).

Displays all unspent outputs in the wallet that can be used for creating new transactions.

§Arguments

  • identifier - Wallet identifier

Fields

§identifier: String

Wallet identifier

§

Mine

Mine blocks (regtest only).

Generates the specified number of blocks and sends coinbase rewards to a default address. This command is only available in regtest mode.

§Arguments

  • num_blocks - Number of blocks to mine

Fields

§num_blocks: u64

Number of blocks to mine

§

RegtestFund

Fund a wallet with 150 BTC (regtest only).

Mines blocks and sends coinbase rewards to the specified wallet, giving it 150 BTC for testing purposes. This command is only available in regtest mode.

§Arguments

  • identifier - Wallet identifier to fund

Fields

§identifier: String

Wallet identifier to fund

§

SendAndMine

Send funds to an address and mine 1 block (regtest only).

Sends the specified amount to the given address and then mines one block to confirm the transaction. This command is only available in regtest mode.

§Arguments

  • identifier - Wallet identifier
  • to_address - Destination Bitcoin address
  • amount - Amount to send in satoshis

Fields

§identifier: String

Wallet identifier

§to_address: String

Destination Bitcoin address

§amount: u64

Amount to send in satoshis

§

BtcToSat

Convert BTC to satoshis.

Utility command to convert a Bitcoin amount to its equivalent in satoshis.

§Arguments

  • btc - Amount in Bitcoin (e.g., 0.001)

Fields

§btc: f64

Amount in Bitcoin

§

ListWallets

List all managed wallets.

Displays all wallets that are managed by the wallet manager, showing their identifiers and associated public keys.

§

WalletInfo

Get detailed information about a wallet.

Displays comprehensive information about a specific wallet, including its address, balance, and public key.

§Arguments

  • identifier - Wallet identifier

Fields

§identifier: String

Wallet identifier

§

CreateWallet

Create a new wallet with an automatically derived key pair.

Creates a new wallet using a key pair derived from the key manager with an automatically incremented index.

§Arguments

  • identifier - Unique identifier for the new wallet

Fields

§identifier: String

Unique identifier for the new wallet

§

ImportDeriveKeypair

Import a derived key pair from a specific index.

Creates a wallet using a key pair derived from the key manager at the specified index.

§Arguments

  • identifier - Unique identifier for the new wallet
  • index - Derivation index for the key pair

Fields

§identifier: String

Unique identifier for the new wallet

§index: u32

Derivation index for the key pair

§

ImportKey

Import a private key to create a wallet.

Creates a wallet using the provided private key in WIF format. The private key is imported into the key manager.

§Arguments

  • identifier - Unique identifier for the new wallet
  • private_key - Private key in WIF (Wallet Import Format)

Fields

§identifier: String

Unique identifier for the new wallet

§private_key: String

Private key in WIF format

§

ImportPartialPrivateKeys

Import partial private keys to create a MuSig2 wallet.

Creates a wallet using partial private keys that are combined to form a complete private key for MuSig2 multi-signature operations.

§Arguments

  • identifier - Unique identifier for the new wallet
  • partial_private_keys - Comma-separated list of partial private keys

Fields

§identifier: String

Unique identifier for the new wallet

§partial_private_keys: Vec<String>

Comma-separated list of partial private keys

§

ExportWallet

Export wallet information.

Exports the wallet’s public and private key descriptors. This is useful for backup purposes or wallet migration.

§Arguments

  • identifier - Wallet identifier

Fields

§identifier: String

Wallet identifier

§

ClearWallet

Clear a specific wallet’s database.

Removes the wallet’s database file, effectively clearing all wallet state and transaction history.

§Arguments

  • identifier - Wallet identifier to clear

Fields

§identifier: String

Wallet identifier to clear

§

ClearAllWallets

Clear all managed wallets.

Removes the database files for all wallets, effectively clearing all wallet state and transaction history.
