# Getting Started with BitVMX

Welcome to BitVMX! This guide will help you get up and running with the BitVMX platform.

## Overview

BitVMX is a platform for disputable computation on Bitcoin. Before diving in, you'll need to:

1. Understand the prerequisites
2. Install the required tools
3. Set up your development environment
4. Run your first example
