# Core Concepts

Understanding the fundamental concepts behind BitVMX is essential for building on the platform.

## Overview

BitVMX is built on several key innovations that enable universal computation verification on Bitcoin. This section covers the foundational concepts you need to understand.

## Learning Path

We recommend reading these concepts in order:

1. **What is BitVMX** - Start here to understand the basics
2. **Architecture** - See how components fit together
3. **Challenge-Response** - Learn the core protocol
4. **Hash Chains** - Understand the data structure innovation
5. **RISC-V** - Explore the computational model
6. **Security Model** - Learn about trust assumptions

## Prerequisites

No prior knowledge of BitVMX is required, but familiarity with:

- Basic Bitcoin concepts (UTXOs, scripts, transactions)
- Cryptographic primitives (hashing, signatures)
- General programming concepts

will be helpful.
